# Proposal action center slices 1.04-1.08

Atlas 1.04 through 1.08 turns proposal decision metadata into an operational staff surface:

- 1.04 adds dashboard proposal action rows ranked by warnings, source-review blockers, and changed-field count.
- 1.05 adds proposal action summary data, including draft proposals that need attention.
- 1.06 carries source-review blocker state into action rows so closeout work is visible before staff open a requirement.
- 1.07 renders an admin Proposal Action Center with warning messages and next-action text.
- 1.08 adds proposal workspace JSON links from the admin action center and queue rows.

The action center remains internal-only and is not safe for patient packet output.
