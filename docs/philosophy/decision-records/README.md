# Architecture Decision Records

Architecture Decision Records explain why Atlas made a consequential technical or product decision.

Each record includes:

- Status
- Context
- Decision
- Consequences
- Alternatives considered

Records are immutable history. If a decision changes, create a new ADR that supersedes the old one rather than rewriting the original rationale.
