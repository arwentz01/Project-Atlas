# Atlas Philosophy

This directory contains the principles and decision records that govern Project Atlas.

These documents are not marketing copy. They are operating constraints for product, design, clinical content, and engineering decisions.

## Contents

- `constitution.md` — non-negotiable product and safety principles
- `architecture.md` — architectural boundaries and dependency rules
- `design-language.md` — interface and interaction rules
- `clinical-principles.md` — clinical content, sourcing, review, and safety standards
- `coding-standards.md` — implementation conventions for the Atlas plugin
- `decision-records/` — Architecture Decision Records explaining why major choices were made

## Decision Test

Every significant feature should answer:

1. Who is this for?
2. What problem does it eliminate?
3. What is the simplest safe implementation?

If those answers are unclear, the feature is not ready to build.
